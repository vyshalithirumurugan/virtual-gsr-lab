# Virtual GSR Laboratory

An interactive educational simulation for studying Galvanic Skin Resistance (GSR), Basal Skin Resistance (BSR), and biofeedback responses.

## Files
- `index.html` — laboratory interface and experiment sections
- `style.css` — page layout and visual styling
- `script.js` — simulator behaviour, resistance graph, stimulus controls, observation table and CSV export

## Features
- Theory and experiment overview
- Simulated skin resistance display in kΩ
- BASAL and ACTUAL mode selection
- Relaxation and tension response simulation
- Stimulus options: mental arithmetic, sudden loud sound, deep breathing, cool water and guided relaxation
- Live resistance graph
- Green/red biofeedback indicators
- Observation table and CSV export

## Run locally
Open `index.html` in a modern web browser.

## Publish with GitHub Pages
1. Create a public repository named `virtual-gsr-lab`.
2. Upload `index.html`, `style.css`, `script.js`, and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.

## Educational disclaimer
This project is a computer-based educational simulation. It generates illustrative resistance values and does not connect to electrodes or measure a real person's skin resistance. It is not a medical diagnostic or treatment tool.
