# Virtual GSR Laboratory

A professional educational virtual laboratory for learning Galvanic Skin Resistance (GSR), basal and actual resistance measurement, and physiological responses to mild stress and relaxation stimuli.

## Modules
- Home and experiment overview
- Aim and learning outcomes
- Theory and measurement principle
- Equipment
- Stimulus types
- Step-by-step procedure
- Data settings
- Virtual GSR setup with simulated live trace
- Side observation panel
- Observation table and CSV export
- Results graph
- Knowledge-check quiz

## Run locally
1. Download or clone this repository.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in a modern web browser.

## GitHub Pages
Open **Settings → Pages**. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.

## Technologies
HTML, CSS and JavaScript. No backend or external database is required.

## Educational disclaimer
This is a browser-based educational simulation. It does not connect to GSR electrodes or a BF017G biofeedback unit and does not measure real skin resistance. The generated signal is illustrative and must not be used for clinical assessment.
